# Datasets Directory

Place your downloaded dataset files here:

1. `soil_types/`
   - Extract the Kaggle "Soil Types" zip here.
   - It should contain 4 subfolders:
     - `Clay/`
     - `Loamy/`
     - `Sandy/`
     - `Sandy Loam/`

2. `crop_production.csv`
   - The CSV file from Kaggle "Crop Production in India".
